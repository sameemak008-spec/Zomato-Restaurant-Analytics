# Zomato Restaurant Analytics — SQL & Power BI

## Project Overview

This project analyzes Zomato restaurant and order data to understand restaurant performance, revenue trends, customer behavior, order patterns, and location-based performance.

The project uses SQL for data preparation and analysis and Power BI for interactive visualization.

## Objectives

- Analyze restaurant performance
- Identify revenue trends
- Calculate Average Order Value
- Analyze customer and order behavior
- Identify high-performing restaurants and locations
- Build an interactive business dashboard

## Dataset

The dataset contains more than 100,000 restaurant/order records.
